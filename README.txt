SHRI GANESH DINING HALL — VERCEL DEPLOYMENT

1. Extract this ZIP. Upload its CONTENTS into your GitHub repository.
   index.html must be at the top level, alongside style.css, menu.js,
   vercel.json and the assets folder.
2. Open https://vercel.com/new and import that repository.
3. Framework Preset: Other
   Root Directory: ./
   Build Command: leave empty
   Output Directory: .
4. Click Deploy.

No API keys or environment variables are required.

The vercel.json file supplies the static-site configuration automatically.
